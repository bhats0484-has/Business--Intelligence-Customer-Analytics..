# Business Intelligence & Customer Analytics Model

An end-to-end data analytics pipeline engineered in Python to segment high-value customer tiers, reduce data dimensionality, and forecast transactional trends using advanced statistical frameworks.

## 📊 Core Methodologies Developed

*   **RFM Segmentation:** Built a dynamic scoring model based on Recency, Frequency, and Monetary metrics to categorize customer value tiers and evaluate behavior.
*   **K-Means Clustering:** Applied unsupervised machine learning algorithms to identify hidden behavioral patterns and group target customer segments.
*   **Principal Component Analysis (PCA):** Executed dimensionality reduction techniques to streamline complex multi-variable data features while preserving maximum variance.
*   **Time Series Forecasting:** Developed statistical models to predict long-term transactional patterns, providing actionable intelligence for strategic decision-making.

## 💻 Tech Stack & Frameworks Used
*   **Language:** Python
*   **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn, Statsmodels
